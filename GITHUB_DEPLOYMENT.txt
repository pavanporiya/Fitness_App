========================================================================
             FITSCAN PRO - GITHUB UPLOAD & FREE LIVE DEPLOYMENT GUIDE
========================================================================

Follow these simple step-by-step instructions to upload your FitScan Pro 
code to GitHub and make it live on the internet for FREE using Vercel 
(highly recommended for Vite React) or GitHub Pages.

------------------------------------------------------------------------
STEP 1: INITIALIZE GIT AND COMMIT YOUR CODE LOCALLY
------------------------------------------------------------------------
Open your terminal inside the project directory ("/home/pavan/Desktop/BMR ADVANCED") 
and run the following commands:

1. Initialize Git repository:
   git init

2. Create a .gitignore file to exclude node_modules (optional but highly recommended):
   echo "node_modules/\ndist/\n.DS_Store" > .gitignore

3. Add all your code files:
   git add .

4. Commit the files to your local repository:
   git commit -m "feat: initial commit of premium FitScan Pro body scanner"

5. Rename your default branch to "main":
   git branch -M main


------------------------------------------------------------------------
STEP 2: CREATE A REPOSITORY ON GITHUB AND PUSH
------------------------------------------------------------------------
1. Open your web browser and go to: https://github.com
2. Log into your account (or create a free account if you don't have one).
3. In the top-right corner, click the "+" button and select "New repository".
4. Name your repository (e.g., "fitscan-pro").
5. Leave it as Public (so you can host it easily), do NOT check any 
   initialization boxes (no README, no gitignore, no license).
6. Click the green "Create repository" button.
7. Under the section "…or push an existing repository from the command line", 
   copy and run the commands in your local terminal:

   git remote add origin https://github.com/YOUR_GITHUB_USERNAME/fitscan-pro.git
   git push -u origin main

   *(Replace "YOUR_GITHUB_USERNAME" with your actual GitHub username!)*


------------------------------------------------------------------------
STEP 3: MAKE IT LIVE FOR FREE! (2 EASY METHODS)
------------------------------------------------------------------------

METHOD A: DEPLOY ON VERCEL (RECOMMENDED - EASIET & FASTEST FOR VITE)
------------------------------------------------------------------------
Vercel is the ultimate hosting platform for React + Vite. It is 100% free, 
detects Vite automatically, and deploys your site in under 30 seconds.

1. Open your browser and go to: https://vercel.com
2. Click "Sign Up" and select "Continue with GitHub" (log in using your GitHub account).
3. Once logged in, click the "Add New..." button and select "Project".
4. You will see a list of your GitHub repositories. Find "fitscan-pro" and 
   click "Import".
5. Leave all settings as default (Vercel automatically detects React, Vite, 
   and handles the build).
6. Click "Deploy".
7. In about 20-30 seconds, your site will be live! You will get a free 
   custom URL like: "https://fitscan-pro.vercel.app"


METHOD B: DEPLOY ON GITHUB PAGES
------------------------------------------------------------------------
If you prefer to host it directly on GitHub Pages, follow these steps:

1. Open your local "vite.config.js" file.
2. Add a base parameter matching your repository name. Change it to look like this:

   import { defineConfig } from 'vite'
   import react from '@vitejs/plugin-react'

   export default defineConfig({
     plugins: [react()],
     base: '/fitscan-pro/',  // <--- ADD THIS LINE (use your exact repo name)
     server: {
       port: 3000,
       host: true
     }
   })

3. Commit and push this change to GitHub:
   git add vite.config.js
   git commit -m "config: add base path for github pages"
   git push origin main

4. Go to your repository on GitHub.com.
5. Click on "Settings" (top tab) -> scroll down to "Pages" in the left sidebar.
6. Under "Build and deployment" -> "Source", make sure it says "Deploy from a branch".
7. Under "Branch", select "main" and folder "/ (root)", then click "Save".
8. In a couple of minutes, your site will be live at:
   https://YOUR_GITHUB_USERNAME.github.io/fitscan-pro/
